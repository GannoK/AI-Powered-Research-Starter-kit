# One-page quick start

1. **Question** — write exactly what you are trying to learn or decide.
2. **Scope** — define population, system, time period, geography, definitions, and exclusions.
3. **Rigor** — choose EXPLORATORY, EVIDENCE-BASED, or HIGH ASSURANCE.
4. **Method** — ADOPT → PROFILE → EXTEND → BUILD.
5. **Search** — record where and how you searched.
6. **Register** — log sources before relying on them.
7. **Extract** — capture what the source actually says, with location/context.
8. **Claim** — state only what the evidence supports.
9. **Challenge** — search for contradiction, alternative explanations, and falsification.
10. **Decide** — keep interpretation, recommendation, and accepted decision separate.
11. **Audit** — verify citations, uncertainty, provenance, and reproducibility.

**A polished answer is not a research result.**
