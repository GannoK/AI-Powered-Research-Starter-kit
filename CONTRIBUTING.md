# Contributing

This project is proprietary.

Substantive contributions intended for incorporation into project-owned intellectual property are not accepted solely because a pull request, issue, patch, document, or other submission is made.

Before substantive contribution:
- the contributor must have authority to provide the material;
- third-party and background IP must be disclosed;
- generative-AI use must be disclosed as required by `LEGAL/AI_ASSISTED_AUTHORSHIP_POLICY.md`;
- the applicable contributor, employment, contractor, or IP-assignment agreement must be executed;
- any compensation, royalty, revenue share, equity, credit, or other consideration must be documented separately where applicable.

For methodological changes:
- distinguish fact from interpretation and recommendation;
- cite authoritative sources for substantive methodological claims;
- preserve contradictory evidence;
- avoid silently changing rigor profiles or authority boundaries;
- update the integrity manifest;
- run `python tools/verify_repository.py`.

Do not add a bespoke method merely because it is novel. Prefer ADOPT → PROFILE → EXTEND → BUILD.

See `LEGAL/CONTRIBUTOR_POLICY.md` and `LEGAL/CONTRIBUTOR_IP_ASSIGNMENT_TEMPLATE.md`.
