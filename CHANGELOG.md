# Changelog

## v0.1.0 — Public Preview

- First public downloadable release.
- Established EXPLORATORY, EVIDENCE-BASED, and HIGH ASSURANCE research profiles.
- Established ADOPT → PROFILE → EXTEND → BUILD method selection.
- Added source register, evidence ledger, claims ledger, conflict/uncertainty tracking, candidate interpretations, recommendations, and accepted-decision separation.
- Added contradiction and falsification workflows.
- Added provenance, source-verification, citation-chain, AI/RAG, prompt-injection, and hallucinated-citation guidance.
- Added reusable prompts, templates, checklists, and workflow guidance.
- Added drop-in workflow installation instructions.
- Normalized repository license to the canonical CC BY 4.0 legal text.

### Public-preview limitation

This release establishes the general framework. Formal domain-specific standards and reporting-guideline reconciliation remains planned before 1.0. High-assurance users should adopt the authoritative standards and qualified review appropriate to their domain.
